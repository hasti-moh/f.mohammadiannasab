Test Automation Engineering

فریم‌ورک‌ها و استراتژی آزمون خودکار

رویکرد من به تست، جایگزینی کارهای تکراری انسانی با اسکریپت‌های قابل اتکا و سریع است.

Playwright Test Automation

طراحی تست‌های خودکار مدرن، چندمرورگره (Chromium, Firefox, WebKit) و موازی با Playwright؛ بهره‌گیری از ویژگی‌های Auto-waiting، رهگیری درخواست‌های شبکه، تست سناریوهای پیچیده UI و اجرای سریع رگرسیون با حداقل Flaky Tests.

  • Cross-Browser & Parallel Execution
  • Network Mocking & API Interception
  • Trace Viewer & Robust Reporting

Selenium WebDriver Frameworks

پیاده‌سازی معماری تمیز با الگوی Page Object Model (POM) در سلنیوم، پیاده‌سازی تست‌های داده‌محور (Data-Driven Testing) برای صحه‌گذاری فرآیندهای مالی و بیمه‌ای، و یکپارچه‌سازی با تست سناریوهای End-to-End.

  • Page Object Model (POM) Design
  • Dynamic Element Handling & Waits
  • Cross-Platform Functional Coverage

API & Integration Testing

تست لایه زیرین نرم‌افزار قبل از UI با Postman؛ طراحی کالکشن‌های تست، اعتبارسنجی Schema، تست پارامتریک مقادیر مرزی و اعتبارسنجی یکپارچگی کدهای پاسخ و توکن‌های احراز هویت.

  • Pre/Post Request Scripts
  • Boundary & Edge Case Validation
  • Status Codes & Contract Testing
